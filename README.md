# BookShop — консольная библиотека книг

Консольное Java-приложение для управления библиотекой книг различных форматов.

## 📌 О проекте

**BookShop** — учебный проект, реализующий систему управления библиотекой. Приложение позволяет добавлять книги, организовывать их по жанрам, искать и сортировать, отслеживать статус прочтения и покупки, а также рассчитывать стоимость коллекции.

Проект демонстрирует применение принципов объектно-ориентированного программирования, наследования, полиморфизма, обобщений и коллекций Java.

## ✨ Возможности

### Управление библиотекой

- Добавление книг в библиотеку
- Автоматическое создание полок по жанрам
- Удаление книг
- Просмотр полного каталога
- Поиск книг по названию
- Поиск книг по автору
- Поиск книг по дате добавления
- Получение списка всех авторов

### Работа с книгами

Приложение поддерживает три типа книг:

| Тип книги | Описание |
|---|---|
| `PaperBook` | Бумажная книга |
| `EBook` | Электронная книга с указанием размера файла |
| `AudioBook` | Аудиокнига с указанием длительности |

Для каждого типа реализован собственный алгоритм расчёта стоимости.

### Дополнительные возможности

- Отметка книг как прочитанных
- Учёт купленных книг
- Просмотр списка непрочитанных книг
- Просмотр списка купленных книг
- Расчёт общей стоимости библиотеки
- Расчёт суммарного размера электронных книг
- Расчёт общей длительности аудиокниг
- Сортировка книг по названию и дате добавления
- Применение скидок к электронным и аудиокнигам

## 🛠 Используемые технологии

- **Java 21** — основной язык программирования
- **Maven** — управление проектом и сборка
- **JUnit 5** — модульное тестирование

## 🏗 Архитектура проекта

Приложение построено на основе разделения ответственности между моделями данных, сервисным слоем и пользовательским интерфейсом.

### Основные компоненты

| Компонент | Назначение |
|---|---|
| `Main` | Точка входа в приложение |
| `ConsoleUI` | Консольный пользовательский интерфейс |
| `Library` | Управление библиотекой и коллекцией полок |
| `Shelf` | Управление книгами определённого жанра |
| `Book` | Абстрактная базовая модель книги |
| `PaperBook` | Модель бумажной книги |
| `EBook` | Модель электронной книги |
| `AudioBook` | Модель аудиокниги |
| `Genre` | Перечисление жанров |
| `BookNotFoundException` | Исключение при отсутствии книги |

### Иерархия классов

```text
                  Book (abstract)
                       |
          +------------+------------+
          |            |            |
      PaperBook      EBook       AudioBook
                       |             |
                 Discountable   Discountable

Book implements Purchasable
```

`Book` содержит общие характеристики книги:

- Название
- Автор
- Количество страниц
- Жанр
- Дата добавления
- Статус прочтения
- Статус покупки
- Размер скидки

Каждый конкретный тип книги реализует собственный метод расчёта стоимости `getPrice()`.

## 🚀 Запуск проекта

### Требования

Перед запуском убедитесь, что установлены:

- JDK 21 или выше
- Apache Maven
- Git

### Клонирование репозитория

```bash
git clone https://github.com/YuryShlyahov/BookShop.git
cd BookShop
```

### Сборка проекта

Для сборки проекта выполните:

```bash
mvn clean package
```

### Запуск приложения

После успешной сборки запустите приложение:

```bash
java -cp target/classes Main
```

Приложение запускается в консоли и принимает пользовательский ввод через `Scanner`.

## 🧪 Тестирование

Для тестирования используется JUnit 5.

Тесты расположены в директории:

```text
src/test/java/service/
```

Покрываются следующие компоненты:

- `LibraryTest` — проверка работы библиотеки
- `ShelfTest` — проверка работы полок и операций с книгами

Тесты проверяют добавление и удаление книг, поиск, сортировку, расчёт стоимости, обработку ошибок и другие операции.

Для запуска тестов выполните:

```bash
mvn test
```

Для запуска тестов вместе со сборкой:

```bash
mvn clean package
```

## 💰 Расчёт стоимости книг

Стоимость книг зависит от их формата.

| Тип | Формула |
|---|---|
| Бумажная книга | Количество страниц × 2 |
| Электронная книга | Размер файла в МБ × 10 |
| Аудиокнига | Длительность в минутах × 1.5 |

Для электронных и аудиокниг предусмотрена возможность применения скидки.

Скидка ограничивается диапазоном от 0% до 100%.
